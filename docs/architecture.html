Factory Inventory Management System

Architecture overview: Vue 3 single-page app, FastAPI backend, in-memory JSON data. No database.

System architecture

Browser talks directly to the API; the API holds all data in process memory.

Tech stack

Small dependency footprint on both sides.

Frontend

  • Vue 3 (Composition API)
  • vue-router 4
  • axios
  • Vite 8, @vitejs/plugin-vue
  • Node 20.19+ or 22.12+

Backend

  • Python 3.11+
  • FastAPI, uvicorn
  • Pydantic 2
  • uv for environments and runs

Data

  • JSON files in server/data/
  • 250 orders, 32 inventory items
  • Regenerated by generate_data.py
  • No database; state resets on restart

Testing and tooling

  • pytest + FastAPI TestClient (backend only)
  • No frontend tests or linters
  • scripts/start.sh, stop.sh
  • Claude Code agents, commands, hooks

Data flow

How a filter change reaches the data and comes back.

  1. The user changes a filter in FilterBar. Time Period, Warehouse, Category and Order Status live as shared refs in useFilters.js.
  2. The view calls getCurrentFilters(). Time Period becomes a month value (a month or a quarter such as Q3-2025).
  3. api.js builds the query string, leaving out any filter set to all, and sends a GET to localhost:8001/api.
  4. A FastAPI route runs apply_filters (warehouse, category, status) and filter_by_month over the in-memory lists.
  5. Results are validated against Pydantic models. The dashboard summary and the reports endpoints aggregate on the fly.
  6. The view stores the raw response in refs; charts and totals are computed properties derived from them.

Observations

Things worth knowing before changing the code.

Gapapi.js calls /tasks and /purchase-orders endpoints, but main.py defines no such routes. The CreatePurchaseOrderRequest model is also unused, and purchase_orders.json is empty.
GapBacklog.vue exists but has no route in main.js.
NoteThe API URL is hardcoded and CORS allows all origins; fine for a local demo, not for deployment.
NoteData is read once at import, so edits to JSON files need a backend restart.
NoteInventory has no time dimension, so the month filter does not apply to it.
